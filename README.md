# 合肥轨道交通网络分析

**关键换乘节点识别与出行鲁棒性：考虑绕行与换乘代价。**

研究问题：中心性高的换乘站，是否也是换乘中断后出行损失最大的站？

## 分工
| 人员 | 主责 | 交付 |
|---|---|---|
| A／第1周 | 数据核验与建网 | 站点、区间、换乘表，网络图 |
| B／第2周 | 中心性、路径评价、单站实验 | 排名、逐站出行损失 |
| C／第3周 | 随机与针对性中断、敏感性分析 | 实验结果、对比图 |
| D／全程及第4周 | 文献、案例、报告与PPT统合、主讲 | 报告、PPT、汇报 |

每人同时交自己的文字和PPT草稿。每周末交接，下一位检查数据和代码。

## 目录

- `data/processed/`：统一清洗结果，格式见 [数据说明](docs/数据说明.md)。
- `src/`：分析代码（目前为待实现骨架）。
- `results/tables/`、`results/figures/`：结果表、图。
- `docs/`：计划书、文献笔记、最终材料。

## 协作
各自建任务分支，完成后发 Pull Request，另一人检查后合并到 main。
不要同时改同一文件。PPT和报告用在线共享文档，定稿再放入 docs。
不上传账号密钥、个人数据或无授权的文献全文。

## 研究口径
- 用物理站点网络计算结构排名，用“站点—线路”网络区分运行和换乘。
- 换乘中断只去掉换乘连接，保留列车通过和上下车。
- 起终点按物理站点等权；不可达比例与仍可达行程绕行代价分开报告。
- 无可靠时间数据时用站数与换乘次数，不把模拟路径经过量称为实际客流。
- 不预设排名差异，保存参数、随机种子和数据日期。
