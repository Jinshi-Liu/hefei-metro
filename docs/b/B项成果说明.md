## 二、口径与前提（务必与其他成员对齐）

1. **结构排名用物理车站网络**：195 节点 / 207 边，同名换乘站合并，与 A 项
   `physical_network.graphml` 同口径。
2. **换乘中断用站点—线路多层网络**：215 个（车站，线路）节点、207 条运行边、
   21 条候选换乘边；排除 S1。已与 A 项 `multilayer_network_main.graphml`
   逐节点、逐边、逐属性核对**完全一致**。
3. **关闭的是换乘连接，不是整站**：删除目标站的换乘边，保留各线路副本节点、
   列车运行边与正常上下车。
4. **统一代价模型（等效站数，不是分钟）**：
   `代价 = 乘车区间数 + 换乘次数 × 换乘惩罚`，基准惩罚 = **2 站**。
   另设 `stations`（惩罚 0）与 `transfers_x1`（惩罚 1）做敏感性对照。
5. **同一组起终点、等权**：195 座物理站的两两无序组合，共 **18 915** 个 OD，
   每对权重 1；同一物理站的多个线路副本**不**重复计为出行需求。
6. **分开报告**：不可达比例、仍可达行程的绕行代价、额外换乘、网络效率分列，
   不把不可达行程塞进“平均出行时间”。
7. **并列处理固定**：最短路按 `(代价, 换乘次数, 乘车区间数)` 字典序破并列；
   排名用竞赛式（并列同名次、下一名次跳号）。
8. **候选换乘边全部为 `pending_verification`**：基准情景把它们视为可通行，
   属于**明确假设**，不是已核实的换乘通道。

### 重要发现：本模型下不可达比例全为 0

**19 座换乘站逐一关闭后，没有任何 OD 变得不可达**（不可达比例全部为 0）。
原因：8 条线路通过 19 座换乘站相互连通，任意单站关闭后仍存在替代换乘路径。

因此在本数据集上，**“不可达比例”不构成区分指标**，单站损失只能由“绕行代价”
体现。这是数据结构的客观结论，不是实验失败；它也直接解释了为什么
`B08` 中 `spearman_*_vs_unreachable` 标记为 `undefined`（而非 0 或 nan）。

> [C 项](../c/C项成果说明.md) 在相同网络和出行口径下进行了多站中断对照。单站不可达比例为 0 仍是有效发现。

## 五、结构排名 vs 出行损失排名

（图：`results/figures/B_fig3_centrality_vs_loss_rank.png`）

- **Spearman ρ（介数 vs 损失指数，19 座换乘站）= 0.461** —— 中等正相关。
- **前 5 名重合仅 2 座**：中介数前 5 = 洪岗、合肥南站、市第三医院、东七里、尧渡河路；
  损失前 5 = 紫庐、合肥南站、繁华大道、西七里塘、东七里。

| 类型 | 站点 | 现象 |
|---|---|---|
| 结构高、损失低 | 洪岗(结构1→损失9)、市第三医院(3→12)、朱岗(6→17)、尧渡河路(5→10) | 中心性高但替代路径好 |
| 结构低、损失高 | 紫庐(8→**1**)、繁华大道(10→**3**)、西七里塘(9→**4**)、云谷路(16→6) | 中介数不高却是“难替代”节点 |

**结论（回答核心研究问题）**：在“换乘中断只删换乘边、起终点为物理站、代价含换乘惩罚”
的口径下，**结构中心性高的换乘站并不必然造成最大的出行损失**。二者只呈中等相关，
且存在明显的双向错位。这与计划书“不预设排名差异”的要求一致，也为“重要但易绕行”
与“重要且难替代”的分类提供了证据。

### 代表站解释

**紫庐（1;7，结构第 8 → 损失第 1）**：在本模型中是 1、7 号线的唯一直接换乘点。基准路径有 1373 个 OD 在此换乘，不代表它们中断后都走同一条线路。以 `万年埠 → 嵩山路` 为例，模型给出的替代路线经合肥南站、图书馆、繁华大道，代价 **8.0 → 38.0**（等效站），换乘 **1 → 3 次**（见 `B_fig5_detour_case.png`）。

**洪岗（3;6，结构第 1 → 损失第 9）**：虽然中介数最高（0.3239，基线有 1523 个 OD
在此换乘），但它位于 3 号线与 6 号线**多交叉**的东南部，关闭后替代路径短、
绕行幅度只有 3.168 等效站，因此总损失反而低于紫庐。

**合肥南站（1;4;5，结构第 2 → 损失第 2）**：三线换乘站，基线有 3614 个 OD 在此换乘
（全站最高），受影响 OD 数最多（3438）；但因为替代入口多，**受影响行程的平均绕行代价相对较低**
（3.414）。这说明“受影响 OD 数多”与“单次绕行代价大”是**两个不同维度**，
报告时必须分开，不能只报一个排名。

## 六、参数敏感性（换乘惩罚）

（图：`results/figures/B_fig4_cost_model_sensitivity.png`）

| 口径 | 换乘惩罚 | 说明 |
|---|---|---|
| `stations` | 0 站 | 纯站数，换乘不额外计价 |
| `transfers_x1` | 1 站 | 换乘按 1 站计 |
| `transfers_x2` | 2 站 | **基准** |

损失指数的 Spearman 秩相关：

- `stations` vs `transfers_x1` = **0.940**
- `stations` vs `transfers_x2` = **0.918**
- `transfers_x1` vs `transfers_x2` = **0.982**

**结论**：在 0—2 站的换乘惩罚范围内，**前 3 名（紫庐、合肥南站、繁华大道）在三种口径下
完全一致、顺序不变**；这一排序只在所测试的 0、1、2 三个取值下成立。
但第 4 名及以后会随口径变化：`stations` 与 `transfers_x1` 口径下云谷路第 4、西七里塘第 7/5；
`transfers_x2`（基准）口径下西七里塘升至第 4、云谷路降至第 6。整体秩相关仍 ≥ 0.918，
属于“头部稳定、中后段轻度重排”的稳健结构。

> C 将惩罚进一步扩展至 3 和 5。惩罚为 5 时前两名互换，前三名集合不变；见 [C 参数检验](../c/C项成果说明.md)。

## 七、模型局限（必须在报告与答辩中说明）

1. **所有代价都是“等效站数”，不是真实出行分钟数**。项目至今没有完整、可复核的
   区间运行时间和换乘分钟数，任何“分钟”表述都属编造。
2. **21 条候选换乘边均为 `pending_verification`**。基准情景把全部候选边视为可通行，
   是**建模假设**；若某条实际不存在，相关结论会变。
3. **同名合并假设**：物理网络把同名站合并为单点，等价于“同名即可换乘”，
   这与 README 的提醒存在张力，需在报告中显式声明。
4. **不模拟**列车容量、排队、班次、末班车；结果是**潜在出行影响**，不是实际客流损失。
5. **OD 等权**，没有真实客流；因此“影响 OD 数”不等于“受影响乘客数”。
6. **只研究地铁内部绕行**，不考虑公交接驳替代。
7. 图 1 的节点位置为 spring 布局，**仅表示拓扑关系**，不反映真实地理距离。
8. 单站中断在本网络上**不会造成不可达**（见第四节），因此不可达指标需要多站中断
   才有意义。
