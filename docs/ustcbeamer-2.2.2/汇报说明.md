[PowerPoint 放映版](合肥地铁换乘可达性_答辩.pptx) · [矢量 PDF](合肥地铁换乘可达性_答辩.pdf) · [可编辑母稿](main.tex)

25 页，16:9。使用 USTC Beamer 与科大校徽，版式文件为 `report-style.tex`。PPTX 与 PDF 逐页对应，带逐页演讲者备注、可点的来源链接；修改正文和图表请改 TeX 及制图脚本后重导。人员姓名集中在 [team.tex](team.tex)，封面和分工页共用。

## 约 20 分钟的讲述安排

| 页 | 建议用时 | 听众要看到的证据 |
|---|---:|---|
| 1–5 | 3 分 30 秒 | 三个问题；同一线网的站名、时刻与换乘建模口径。 |
| 6–12 | 6 分钟 | 静态换乘关闭。区分失联和绕行，解释介数与损失排名不同、样本退出及 AUC。 |
| 13–18 | 5 分钟 | 夜间班次链和返校算例；比较逐线加开、三线同时加开，不直接相加单线结果。 |
| 19–22 | 4 分钟 | 线路日量怎么预测、分时 OD 怎么估计，关键站排名与区间方向怎么读。 |
| 23–24 | 1 分 30 秒 | 结论、复现、来源及分工。 |
| 25 | 另计 | 答疑。可回到第 11 页核查样本，第 18 页核查组合，或第 22 页核查 OD 与区间的区别。 |

以上按《期末说明》的建议评价维度组织，不假定固定打分权重。

## 编辑与导出

以下命令在本目录运行。已存在 `figures/report/*.pdf` 时，只改姓名或文字可跳过制图。输入快照若变更，需重跑各实验，并核对正文与备注的数字。

```powershell
python make_figures.py
xelatex -halt-on-error -interaction=nonstopmode main.tex
xelatex -halt-on-error -interaction=nonstopmode main.tex
Copy-Item main.pdf '合肥地铁换乘可达性_答辩.pdf' -Force

# 仅导出 PowerPoint 需下列两个包
python -m pip install PyMuPDF python-pptx
python export_pptx.py
```

每个 frame 在 `main.tex` 里有一条纯文本 `\note{...}`，导出为对应页的 PowerPoint 备注（不要在备注中嵌套 TeX 命令）。制图字体优先用微软雅黑，也支持 Noto Sans CJK SC。
