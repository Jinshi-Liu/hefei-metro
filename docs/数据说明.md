# 当前数据口径

## 实际输入（data/processed）
- line1_stations.csv … line8_stations.csv：line、sequence、station、status。按sequence建立相邻运行边。
- s1_stations.csv：A保留的扩展情景，不进入B主分析。
- transfer_edges.csv：station、line_a、line_b、edge_type、status。B从此表读取候选换乘连接。
- transfer_candidates.csv、transfer_verification.csv、transfer_edge_verification.csv：候选连接与核验过程资料。
- segment_running_times.csv：运行时间整理表，当前分析不使用未证实的分钟参数。

CSV按UTF-8（可带BOM）读取。当前模型用站名识别物理站，用“站名_L线路编号”识别线路副本；同名合并是显式假设，不是已完成的通道核验。

## 模型与输出
- 结构中心性：物理站点网络。
- 换乘中断：站点—线路网络；运行边保留，仅去掉指定站点的换乘边。
- 候选边原属性 traversable=false；路径模块在明确的基准假设下启用，并非NetworkX自动按属性过滤。
- 代价 = 乘车区间数 + 换乘次数 × 惩罚（0、1、2）。
- 每个无序物理站点对只计一次，不用副本数增加需求权重。
- 无客流、容量和完整运行时间，因此结果不代表真实乘客损失、分钟数或拥挤程度。

数据来源及未核实项目见 [A数据来源](a/data_sources.md)。正式结论前须固定并核验对应运营日期。
原始证据应补充到 data/raw/，在 sources.csv 登记。当前空登记表不表示来源已采集完整。
