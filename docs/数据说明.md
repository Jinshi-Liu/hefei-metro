# 数据约定

CSV 使用 UTF-8，站点ID作为字符串保留；时间统一为分钟。以下表目前只有表头，不是真实数据。

- stations.csv：station_id（唯一物理站ID）、name、longitude、latitude。
- segments.csv：line_id、from_station_id、to_station_id、travel_time_min。基础模型按双向运行处理，每对相邻站只录一行；若存在例外，先更新模型约定。
- transfers.csv：station_id、from_line_id、to_line_id、transfer_time_min。基础模型按双向换乘处理，每个线路对只录一行。

原始资料放 raw，来源记在 raw/sources.csv：文件名、链接或出处、对应日期、获取日期、备注。
时间缺失留空，不填0；第一周决定是否采用时间模型，不混用分钟和站数。
跨线换乘使用线路副本站点连接，起终点仍按物理站点统计。
